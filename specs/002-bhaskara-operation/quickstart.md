# Quickstart: Bhaskara Operation

## Running the App
1. Ensure you have Flutter installed.
2. Run `flutter run` in your terminal or launch from your IDE.
3. Click the new "Bhaskara" operation button (it will be added to the extra operations list automatically due to the `OperationRegistry`).

## Testing the Feature
1. **Interactive Check**: Click "Bhaskara".
2. Enter values: `a=1`, `b=-3`, `c=2`.
3. Press Calculate.
4. Verify the display shows `[2.0, 1.0]`.
5. Run unit tests via `flutter test`.
